## 原始貼圖像素與畫布範圍版本

本輪使用自製 800×600 藍底測試圖（含綠色直帶與一像素紅線）及 200×150 白底，未編輯既有使用者圖片。

1. 在 800×600 原圖按 Ctrl+A/C，切到 200×150 白底按 Ctrl+V：浮動貼圖維持 800×600，畫布仍是 200×150。可看到並拖動框外內容。
2. 把貼圖移到 (-250, -30)，按「合併」及 Ctrl+S。讀回實際輸出 PNG，尺寸 200×150，(0,20) 綠、(1,20) 紅、(2,20) 綠，一像素細節沒有重採樣。
3. 拉外框右下控制點，畫布變為 300×200；原有細線與內容維持原尺寸，右側和底部增加白色區域。正常關閉後自動保存，讀回 PNG 確認新增區域白色、紅線仍在。
4. 剪貼簿仍為 800×600 原圖。Ctrl+N 的寬高預設 800×600，按 Enter「建立空白」；關閉保存後讀回 PNG，800×600 且全部白色。
5. 再按 Ctrl+N，選「貼上剪貼簿並新增」：新分頁與畫布均為 800×600，讀回實際輸出 PNG，與來源逐像素完全一致。
6. 「畫布大小」開啟獨立視窗，顯示寬、高、白色／透明新增區域背景，以及固定左上角、不縮放圖片與合併的說明；取消保留原尺寸。

本輪 C# 回歸測試 18/18 通過，包括完整既有編輯流程、合併／復原還原完整浮動貼圖、透明擴張、外框拖曳只產生一個歷史版本及縮小畫布。符合視窗的顯示比例另外預留外框控制點與尺寸標籤空間，不改輸出像素。

正式 release 再啟動確認沒有舊分頁；Ctrl+Shift+V 直接新增 800×600 圖片，三個外框控制點與底部尺寸標籤均可見，再關閉測試分頁留下空白工作台。release、v2、v3 的 SHA-256 同為 `0A9FDDB22C2E5D118D126E52BC8FC62A6AA0393435FB98687C13443B100DB7A8`。

## 本輪物件編輯版本

使用本輪新建的白色測試畫布，沒有修改既有使用者圖片：

1. 啟動空白，沒有恢復舊分頁；Ctrl+N 建立 1280×720 獨立畫布，紅點表示未保存。
2. 七色數字圖章選紅色、中尺寸：在游標中心放置 1，周圍八個控制點，下一個編號為 2。
3. 保持圖章工具直接拖移 1；在空白處新增 2，下一個為 3，沒有切回選取。
4. Ctrl+C 複製選中圖章，Ctrl+V 貼入同一分頁，成為圖片物件；直接拖移並拉右下角放大，比例保持。
5. Ctrl+A 顯示整張圖片的選取範圍；Ctrl+S 保存，分頁轉綠，實際 PNG 已寫入。
6. 程式選項的「一般」頁看到開機自動執行、收在通知區與關閉後不重開分頁的說明。保留未勾選，沒有替使用者開啟開機執行。
7. Ctrl+Z 產生未保存修改，Alt+F4 關閉。輸出 PNG SHA-256 從 `F5DE2F19…3966EF` 改為 `13C38727…70304E`，文件 `Open=false`，確認關閉保存生效。
8. 正式 release 以 `--tray` 啟動：程序存在、MainWindowHandle=0、視窗清單沒有編輯器；再次執行同一檔案後恢復空白工作台，沒有舊分頁。release、v2、v3 的執行檔 SHA-256 均為 `5810714B62AAE4E39E4170DD9B3F97D7D4E950641AED8BF3DB90D0147C290B43`。

自動測試 `CanvasUserFlows.cs` 另覆蓋框線工具直接拖移、圖片等比縮放、垂直箭頭端點、全選及關閉後不進入恢復列表。啟動命令的路徑引號有測試；實際 Windows 重新登入未在本輪執行。

通知區：先前桌面測試確認最小化後 Ctrl+Alt+2 仍開啟頂端模式列。避免切換 ShowInTaskbar 重建 HWND；視窗、執行檔及 NotifyIcon 改用同一個自製多尺寸圖示。

使用發行版與兩張測試圖 A、B，確認：

1. 透過單一實例的檔案開啟入口，兩張圖片各自加入 Tab。
2. 在 B 圖畫箭頭後切換至 A，A 保持原圖；切回 B，箭頭仍在。
3. 在 B 按 Ctrl+Z，箭頭消失，介面顯示已復原並保存。
4. 正常關閉程式，檢查兩份文件的保存內容：A 沒有新增編輯版本，B 保有兩個歷史版本且目前選取原圖；輸出 PNG 與原圖一致，兩個 Tab 都標記為開啟。
