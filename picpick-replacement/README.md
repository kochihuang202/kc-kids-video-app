# 截圖工作台 · Capture Workbench

Windows 桌面截圖與物件編輯器：上方擷取模式列、框選、捲動擷取、獨立分頁、可再次拖曳的標註、連續編號圖章與貼圖。

## 執行

執行 `artifacts/release/CaptureWorkbench.exe`。獨立發行版內含 .NET 執行環境，不需要安裝 SDK。

先前的 `artifacts/v2` 與本輪測試的 `artifacts/v3` 同步到相同版本；以 `release` 為主要入口。

- `Alt+2` 叫出上方擷取工具列，可當場切換框選與捲動。
- 如果 PicPick 已占用 `Alt+2`，會自動嘗試 `Ctrl+Alt+2`；也可以直接按「開始擷取」。關閉占用快捷鍵的程式後，按快捷鍵按鈕重新註冊。
- 框選：拖曳需要的範圍，放開即擷取。
- 捲動：切換「捲動擷取」，框選可捲動的內容區域，程式自動捲動。**按 Esc 在需要的位置正常結束；連續確認畫面不再前進後也會自動結束。** 不需要捲到最底才算完成。
- 每次擷取加入獨立 Tab，標題只顯示時間。綠點表示已保存，紅點表示修改中或尚未保存。捲動中保留綠色範圍框，框線在擷取矩形外側。
- `Ctrl+W` 關閉分頁，圖片仍保留。關閉分頁或整個程式時自動保存，下次啟動空白，不重開所有舊分頁。

## 編輯與保存

工具包含選取、箭頭、文字、框線、橢圓、直線、畫筆、螢光標記、馬賽克、裁切、旋轉、縮放與調整尺寸。

- `Ctrl+N` 新增白色／透明背景畫布，預設使用剪貼簿圖片的尺寸。「建立空白」只建立同尺寸空白；「貼上剪貼簿並新增」直接建立內容與畫布尺寸完全一致的新圖片。`Ctrl+O` 開啟圖片。
- `Ctrl+V` 貼到目前畫布，保留原始像素與尺寸，成為立即選中的獨立圖片物件，可直接拖曳與縮放；大圖不會自動縮小，也不會擴大既有畫布。合併前可移到畫布外，灰色區域預覽框外內容。沒有畫布時才開新分頁；`Ctrl+Shift+V` 直接貼到同尺寸新分頁。「檔案 → 從檔案貼上」可插入外部圖片。
- 「合併」或 `Ctrl+Enter` 將全部浮動物件固定到目前畫布，只保留框內內容；`Ctrl+Z` 可復原合併，恢復完整貼圖與可拖曳狀態。
- 拖曳畫布右側、底部或右下角的外框控制點，或按「畫布大小」輸入寬高，可調整實際輸出範圍。固定左上角，放大增加白色／透明空間，縮小裁切底圖，圖片像素不縮放；「縮放圖片」則會改變圖片與物件的像素尺寸。
- `Ctrl+A` 全選圖片；`Ctrl+C` 複製選取區域、選中物件，或整張圖。PNG 剪貼簿格式保留透明度。
- `Ctrl+Z` / `Ctrl+Y`：目前文件的復原／重做，不影響其他分頁。
- 擷取完成自動保存；編輯、復原與重做只留在記憶體，不連續寫檔。按「保存」或 `Ctrl+S` 才寫入，成功後轉綠。關閉時也會自動保存；保存失敗保留視窗與編輯供重試。
- 預設儲存於「文件\CaptureWorkbench」。日期資料夾內是目前的 PNG；`.documents` 保留原圖、版本與恢復資訊，**不要只保留 PNG 就刪除 `.documents`，否則無法恢復歷史**。
- 新截圖以擷取當下時間命名，例如 `2026-10-16 13-45-30.png`，同一秒重名才加 `(2)` 流水號。編輯與重新啟動沿用原檔名。
- 每份文件最多保留 40 個歷史引用；已保存版本與 `.recovery` 捲動檢查點保留在磁碟，不會在啟動時自動打開。
- 標註保留為獨立物件。在繪圖工具下也能直接選取既有物件拖曳，不必切回選取；圖片／圖章／框線有八個控制點，直線／箭頭用兩個端點調整。拉圖片與圖章的角點時保持比例，Shift 可解除；Ctrl 可在物件上強制新增。Delete 刪除物件，Esc 取消操作與選取。
- 數字圖章有七種色系、白邊與陰影、圓形／矩形及三種大小，置於游標中心。放下後立即選中，拖移不遞增，空白處繼續新增下一個編號。工具列可改現用及下一個編號。

## 通知區與開機

最小化按鈕或「縮到通知區」收到右下角，快捷鍵持續有效。雙擊圖示恢復，右鍵可擷取或離開；再執行同一程式也可恢復視窗。視窗、執行檔、通知區使用同一個自製截圖圖示。

「選項 → 程式設定 → 一般」提供「登入 Windows 時自動執行」，預設不勾選。勾選並保存後，透過目前使用者的 Windows Run 項目，以 `--tray` 啟動並收在通知區。移動執行檔位置後請重新取消／勾選此設定。

## 第一版的範圍

捲動擷取依本機 PicPick 7.4.1 的逆向證據重建精確影像帶／亮度後備比較，標準捲軸優先、滾輪備援，不依賴瀏覽器擴充功能。包含固定區域處理、暫時不動重試、低信心停止與恢復檔。詳細證據與限制見 `research/README.md`。

這仍是需要真實程式比較的原型，**尚未證明達到 PicPick 的穩定程度**。請優先框選會捲動的內容，避開大型固定側欄、影片與動畫。超慢載入、重複圖樣、無限捲動、自訂 GPU 控制項與更高權限的程式可能需要進一步處理。

程式不提升權限、不變更 PicPick、不占用已被註冊的快捷鍵。單張影像上限為一億像素，超長內容應分段擷取。一般／游標圖章仍非原版完整圖庫；數字外觀以自有繪圖程式重建，未宣稱逐像素等價。

## 建置與檢查

需要 Windows x64 與 .NET 10 SDK。無第三方應用套件依賴。

```powershell
dotnet run --project tests/CaptureWorkbench.Tests.csproj
dotnet publish CaptureWorkbench.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/release
```

測試涵蓋位移對齊與固定標頭、手動完成保留像素、無進展、錯誤對齊拒絕、分頁隔離、復原與重新載入、自動輸出、連續檔名唯一、寫入失敗與重試，以及到底的多次確認。它們不取代真實網頁與桌面程式上的擷取驗收。
