# 同步／更新／保存通知：左下角燈號＋原版通知

2026-11-14，使用者要求：自製的白色提示框太醜，改成 FlexNote 樣式；主程式與資料的新版本由左下角燈號管理。

## 行為

| 通知 | 顯示方式 |
|---|---|
| 進度：正在同步工作區、正在準備程式更新、等待資料到齊、新版更新檔尚未到齊、使用本機版 | 只在燈號：琥珀色，滑鼠停留看說明；有細節時點燈號可「查看版本」 |
| 需要決定：發現程式新版本、兩台都有新版本 | 燈號變藍＋一次原版通知（「點左下角燈號…」）；點燈號出現「更新並重新啟動」或「查看版本／保留本機版本」 |
| 完成：已更新內容、已保留本機版本、程式已更新 | 原版成功通知（55153.fz，殼層掛載的通知區） |
| 失敗：保存未完成、自動／背景保存未完成、更新未完成 | 原版錯誤通知 |

燈號沒有待辦事項時與以前相同：綠＝已備份、紅＝尚未備份。`data-state` 不變；`data-notice` 為 none／progress／attention。
新開視窗重送最後的通知時只恢復燈號，不重播舊通知。

## 修正：同步恢復後提示不消失

同步檢查只在「未就緒」時發通知，就緒後沒有任何通知，舊白框因此一直顯示「正在同步，等待資料到齊」。現在就緒時送出 `state:'clear'`，燈號上的同步事項隨之清除（`src/main/live-sync.cjs`）。
