# 設定框架與六個分類（0.5.4）

依 2026-11-03 使用者截圖保留：編輯器、外觀定制、快捷鍵、本地存儲與備份、附件管理、關於。帳號、AI、雲服務、生態連接不掛入。這輪是可擴充的框架與既有功能整合，不聲稱其餘編輯器／外觀／快捷鍵設定已實作。

## 原版來源與整合

先查私人原版 `78507` 的完整 `iO` 設定父函式。原版以 Modal93.R、ModalContent96211.A、Tabs71521.n、Tab2692.r 組成 4xl／80vh 視窗，左側 w-52 導覽、右側 ml-8/pr-8/pt-8 可捲動內容。六類圖示沿用原版對應模組：46679、621、49700、65728、63217、19711。

`settings-frame.mjs` 直接使用上述原版元件、相同 provider 與版型，沒有重畫整套彈窗。保留已測試的 storage-settings IPC／資料夾選擇／名稱保存／快照／還原／更新 handler，將原來 DOM 欄位移入原版 Tabs 的受控容器，分頁卸載時放回隱藏欄位庫，保留值和真正的事件處理。

- 原版 ModalContent 的 getDialogProps 決定內部 ID，不能假定外加 id 會保留；使用明確內層 settings 容器提供穩定樣式與既有測試入口。
- 原版 Tabs 的 base 是導覽本身，不能將它設成 width:100%，否則會擠扁內容欄。已用截圖查出並修正，測試要求內容欄寬度超過 400px。
- 配合原版 ui.settingPanelOpen／22676.zJ，開窗與欄位搬入後將焦點交給所選分頁；動作後還原焦點。保留 busy 時不可意外關閉的規則，不靠固定延遲猜測讀取或保存完成。

## 現在可用與保留框架

| 分類 | 目前內容 |
|---|---|
| 編輯器／外觀定制／快捷鍵 | 分類及可擴充頁面，明示後續提供；沒有假開關或假保存 |
| 本地存儲與備份 | 既有 OneDrive 路徑、真實資料夾選擇／檢查／開啟、電腦名稱、本機資料位置、立即備份、快照掃描與載入 |
| 附件管理 | 實際 files catalog 的數量與總大小；未新增刪除／GC |
| 關於 | 當前 package 版本及既有程式更新檢查 |

目前工作區資訊顯示實際白板／卡片數量，識別碼放詳細資訊。底層有 workspaceId 與同步／快照身分，但每個本機目錄仍只使用一份目前工作區；沒有把「載入另一份快照」宣稱為多工作區建立、切換及各自持久保存。後續多工作區須另處理 catalog、資料目錄、CAS、視窗和交換綁定。
