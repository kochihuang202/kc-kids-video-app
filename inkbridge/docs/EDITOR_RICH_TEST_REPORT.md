# 0.4.0 自製版本凍結紀錄

本檔是歷史紀錄，不是目前開發方向或驗收完成宣告。

0.4.0接回公開Lexical標準節點、補貼上保真與保存測試，但仍使用自製Canvas適配器。之後使用者指出基本編輯／顯示渲染有落差、雙擊新增及右鍵平移不符需求，因此不作為合格的FlexNote重製交付，停止沿此底座擴寫。

當時測試實際覆蓋：rich HTML節點／AST、SQLite正常重開、100段基礎長文、code Tab/Undo、checkbox、table Tab，以及部分既有回歸。這些不能代替實際LOD畫面、全部字形排版及原版互動完整性。captureText helper使用完整量測，不等於每個LOD實際畫出的內容；測試接縫不充分。

保留原檔、測試及舊成品供回復與比對；不刪除、不把舊測試數字改寫為新移植版驗收。後續原模組移植進度與啟動方式以ORIGINAL_PORTING_PROGRESS.md為準。
