# 閱讀介面契約

兒童共用一列固定導覽：設定、回到書架、回到封面。書架固定 `/`；封面固定 `?book=<id>`；書架的封面欄空白，封面自己的該欄標示當前位置。三欄不因模式改變，不隨捲動隱藏。目錄及控制項從左抽屜展開，背景變暗，抽屜獨立捲動，關閉不移動正文。

書架 → 本集共同封面 → 選模式目錄。依 2026-10-20 使用者要求，封面每張模式卡各只有一個主要入口：閱讀理解的「選擇單元」、時光悄悄話的「選擇篇章」。不在封面直接開始或接著讀；開始／接著讀保留於各自的目錄頁，沿用各模式獨立保存的位置。閱讀中沒有另一模式的捷徑；回封面才能切換。悄悄話目錄 `mode=whisper`，正文 `chapter=N`；理解目錄 `mode=practice`，正文加 `scene=N`。兩模式獨立位置，不以編號互跳。舊 `level=extra` 正規化成同一理解單元。

文章先於練習，題目在文章下方，可回看、略過、重試、直接看解析。頁尾字數只算正文的文字和數字。注音、字級、詞語提示及語速全站共用。保存不可用時仍可閱讀；進度於連線恢復後重送。

父母模式僅從設定最下方按住三秒進入；放開、移出、取消指標即取消。鍵盤可持續按住空白或 Enter。舊父母網址先出現長按確認；未解鎖不載入或顯示家長統計。解鎖只存在頁面記憶體，返回孩子、重新整理、背景／離頁後重新鎖定。返回孩子保留原路由及閱讀錨點。不提供帳號或 PIN，也不宣稱長按能防止孩子刻意進入。

父母頁區分閱讀位置與理解程度，顯示作答、提示、重試、解析、自由筆記與舊版短文紀錄；不以閱讀到哪裡當能力分數。頁尾提供由內容／介面產生的版本碼與更新時間，API health 版本須一致。

驗收採 820×1180、1180×820 及 390×844 Chromium 模擬、最大字級與注音開關。這些是瀏覽器模擬，不代表已用實體 iPad Safari 測試。
